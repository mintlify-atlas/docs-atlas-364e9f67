Shattered Reality is an asymmetric horror-survival game built in Luau on Roblox. Each round, one or more killers hunt a team of survivors across handcrafted maps. Survivors must outlast the clock, complete objectives, or outmaneuver their pursuers — killers must eliminate every survivor before time expires.

This documentation covers the game's architecture, character system, gamemodes, core Luau systems, and everything a developer needs to extend the project with new killers, survivors, maps, or gamemodes.
