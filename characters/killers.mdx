Killers are the hunting role in Shattered Reality. Every killer has 1 000 HP (except !Pursuer at 3 500), a `ChaseConfig` that drives proximity-based music layering, and an `AbilityInfo` table with at least an M1 basic attack and two or more special abilities. Sprint stamina is shared across all killers at a starting pool of 115 (350 for !Pursuer), and speed tuning varies per character to give each kit a distinct feel.

<Note>
  All numeric values on this page are sourced directly from each killer's `Config` ModuleScript in `ReplicatedStorage/Systems/Characters/Killers/`. Values shown are the base defaults before any skin override is applied.
</Note>

## JohnDoe

John Doe ("The Corrupted Pursuer") is a **Rushdown**-class killer built around closing gaps quickly with a short-cooldown basic attack and a mobility dash. He has a special emotional relationship with JaneDoe that triggers an alternate chase theme during Last Man Standing when she is the last survivor.

<Accordion title="LMS emotional data (JaneDoe relation)">

  When JaneDoe is the last survivor and John Doe is the killer, the Manager replaces the standard chase theme with an alternate audio track defined in `LastManStandingEmotionalData`:

  ```luau
  Relations = { "JaneDoe" },
  LastManStandingEmotionalData = {
      JaneDoe = {
          ThemeID = "rbxassetid://114037366568111",
      },
  },
  ```

  The Manager's `bind_server_dialogue` function also fires contextual dialogue lines across intro, roam, kill, last-survivor, stun, and match-win events. A dialogue lock attribute (`JohnDialogueLockUntil`) prevents overlapping lines; roam lines fire every 38–52 seconds.

</Accordion>

## !Pursuer

!Pursuer ("The Relentless Hunter") is a **Chaser**-class killer with dramatically amplified health (3 500 HP) and stamina (350), intended for special/event-mode play. The `!` prefix marks it as a limited-access character — see the [Overview](/characters/overview) for how the loader handles this naming convention.

<Warning>
  !Pursuer's `MaxHealth` of 3 500 and `MaxStamina` of 350 mean standard stun and damage thresholds tuned for normal killers will not function the same way. Systems that reference `Characters.Global.StaminaTuning.LMSCaps` should account for the extended pool.
</Warning>

## Reading killer configs at runtime

```luau
local Characters = require(game.ReplicatedStorage.Modules.Data.Characters)

-- Full merged config (base + skin override + rig reference)
local config = Characters.GetActorConfig("Killer", "JohnDoe", "Default")
print(config.MaxHealth)          --> 1000
print(config.SprintConfig.SprintSpeed) --> 30

-- Single normalized ability config
local impale = Characters:GetAbilityConfig("Killer", "JohnDoe", "Impale")
print(impale.KnockbackForce)     --> 18
print(impale.Amount)             --> 100  (normalized from HitboxAmount)

-- Check class membership
local isRushdown = Characters:IsActorInClass("Killer", "JohnDoe", "Rushdown")
```

<Tip>
  The `Manager/init.luau` (or `Manager.luau`) for each killer is loaded by `Characters.GetBehaviorModule("Killer", name)`. It exposes an `Abilities` array and lifecycle hooks (`Init`, `OnExecute`) that the gameplay layer calls — you do not need to require it directly from data code.
</Tip>
